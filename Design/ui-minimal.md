## 2. ミニマルな情報設計の案と理由

**基本方針**：「いまの文脈で本当に必要な操作だけを常に見せ、設定頻度の低いもの・既定状態のもの・対象が無いものは、選択・ホバー・折りたたみ・メニューへ退避する。機能とショートカットは一切削らない。」

### 2.1 ウィンドウツールバー（6 項目 → 常設 3 項目）
- **残すもの**: 左に `素材パネル (⌘1)`、右に `書き出し (⌘E)` と `インスペクタ (⌘2)`。
  - 作業中に状態を確認・実行する最上位の枠（左ペイン・右ペイン・最終出力）だけに絞り、アイコン同士の紛らわしさ（保存 vs 書き出し）を解消した。
  - 無音カット中・音声書き出し中だけ進捗インジケータを動的に表示する。
- **退避したものと到達経路**:
  - `開く` → `ファイル > 開く… (⌘O)` およびウィンドウへのドロップ。
  - `保存` → `ファイル > 保存 (⌘S)` / `別名で保存… (⇧⌘S)`。未保存状態はウィンドウタイトルの「— 編集中」で引き続き分かる。
  - `無音カット` → `編集操作 > 無音を詰める` に加え、タイムライン見出し右側の `…` メニューにも配置（マウスだけで届く）。

### 2.2 再生操作の行（プレビュー直下に一本化）
- **残すもの**:
  - 左: **タイムコード + 総尺** (`00:00.00 / 00:19.00`) をここに一本化。下段が「字幕」タブのときも常に総尺が見える。
  - 中央: **再生 / 一時停止**ボタンを `ZStack` で厳密に中央配置。
  - 右: 待機時は控えめなマイクアイコンのみ。録音中は従来どおり `LevelMeter` + 赤い `停止` ボタンへ展開する。
- **退避したものと到達経路**:
  - `先頭へ` / `1 フレーム戻る` / `1 フレーム進む` / `末尾へ` → 再生バーにホバーすると再生ボタンの左右に現れる。あわせて `編集操作` メニューにも `先頭へ移動` / `末尾へ移動` / `マイクから録音` を追加し、`←`/`→`/`Space`/`K` などのショートカットは従来どおり。

### 2.3 タイムラインの見出し行とトラック見出し
- **タイムライン見出し行**:
  - 二重表示だったタイムコードを削除し、高さも `34pt → 32pt` に引き締めた。
  - 常設の編集ボタンは未選択でも効く **分割 (`S`)** のみ。**複製 (`D`)**・**削除 (`Delete`)** はクリップ選択中だけ選択サマリーメニューと並べて表示する（クリップの右クリックメニューにも `コピー` / `切り取り` / `削除して詰める` を拡充）。
  - 右側には `…` メニュー（無音を詰める・切り抜き・吸着・トラック追加）と、コンパクトなズーム操作（小スライダー `84pt` + `−`/`+` + 全体表示 `F`）をまとめた。
- **トラック見出し**:
  - `トラック追加 (+)` をズーム横から **トラック見出し列の右上（ルーラー行の空きスペース）** へ移し、対象との空間的な対応を一致させた。
  - `非表示` / `ミュート` / `ロック` の 3 ボタンは **既定状態（表示・非ミュート・ロック解除）では隠し、ホバー時に表示**する。一方、**有効な状態（非表示中・ミュート中・ロック中）はオレンジ色で常時表示**し、状態の取り違えを防ぐ。右クリックメニューからも切り替えられるようにした。
  - これにより見出し列の幅を `176pt → 148pt` にスリム化し、タイムラインレーンの表示幅を広げた。

### 2.4 インスペクタ（選択連動 + クリップ種別最適化 + 段階的開示）
- **選択連動の自動開閉（既定で閉じる）**:
  - クリップ未選択時はインスペクタを自動的に閉じ、プレビュー画面を横幅いっぱいに使えるようにした。
  - クリップを選択すると自動で開き、選択を解除すると自動で閉じる。
  - `⌘2` またはツールバーのインスペクタボタンで手動開閉でき、未選択時に手動で開くと従来どおり「プロジェクト設定」を表示する。さらに `ファイル > プロジェクト設定… (⇧⌘P)` からシートでもいつでも開ける（クリップ選択中でも開ける）。
- **クリップインスペクタの再構成**:
  - **ヘッダ圧縮**: クリップ名（テキストならテンプレート名）と `開始 · 尺` をコンパクトな 2 行（タイトル + モノスペース副題）に統合。
  - **種別に応じた表示**:
    - テキストクリップ: **テキスト props とテンプレート切替を最上部へ移動**。`色`・`真偽値` props は 1 行の横並びにして縦の伸びを抑えた。不要だった `音量` を非表示に。
    - 映像・画像クリップ: `配置`（拡大・位置 X/Y・不透明度。変更時のみリセットボタン出現）と、音声を持つ映像のみ `音量`（見出し＋ラベル重複を解消し 1 行化）を表示。
    - 音声クリップ: `音量` のみを主役にし、無関係な `配置` を非表示に。
  - **段階的開示 (`DisclosureGroup`)**:
    - `フェード` は既定が 0 秒のため折りたたんで最下部へ配置。値が入っているクリップを選ぶと自動で開き、閉じた状態でも現在値を右端に要約表示する。
    - プロジェクト設定の `動画の範囲` も、自動追従のあいだは折りたたんで「自動」と表示し、明示指定されたときだけ展開する。

### 2.5 その他の細部整理
- **プレビュー空状態 (`PreviewView.swift`)**: 黒背景に対して沈んでいた案内文言のコントラストを改善（`.white.opacity(0.55)`）。
- **字幕タブ (`TextClipsPane.swift`)**: 行ごとの `削除` アイコンをホバー時のみ表示にし、行の右クリックメニュー（再生ヘッド移動・複製・削除）を追加。字幕 0 件時はテンプレート絞り込みを隠す。
- **書き出しシート (`ExportView.swift`)**: 読み取り専用の解像度・FPS・長さをタイトル直下の 1 行サマリーにまとめ、グリッドを設定項目（コーデック・画質＋目安・出力先）だけに絞って不要な下部余白を削った。

### 2.6 機能の到達経路まとめ（欠落ゼロの確認）
| 退避・変更した操作 | 新しい到達経路 | ショートカット |
|---|---|---|
| 開く / 保存 | `ファイル` メニュー / ドロップ | `⌘O` / `⌘S` / `⇧⌘S` |
| 無音カット | `編集操作 > 無音を詰める` / タイムライン `…` メニュー | — |
| プロジェクト設定（解像度・FPS・背景色・動画の範囲） | `ファイル > プロジェクト設定…` / 未選択時にインスペクタを開く | `⇧⌘P` / `⌘2` |
| 動画書き出し | ツールバー / `ファイル > 動画を書き出す…` | `⌘E` |
| 先頭へ / 末尾へ / コマ送り | 再生バーのホバー / `編集操作` メニュー | `←` / `→` (`⇧` で 10f) |
| マイク録音 | 再生バー右端のマイクアイコン / `編集操作` メニュー | — |
| 削除 / 複製 | 選択中のタイムライン見出し / クリップ右クリック / `編集操作` メニュー | `Delete` / `D` / `⌘D` |
| トラック追加 | トラック見出し列右上の `+` / タイムライン `…` メニュー / レーン右クリック / `編集操作` メニュー | — |

| 字幕行の削除 | 行ホバー時の削除アイコン / 行右クリック / チェック一括削除 | — |

## 3. 変更したファイルと要点

- `Nanovid/UI/ContentView.swift`

  - `TrackHeaderView` の非表示・ミュート・ロックをホバー表示＋有効時オレンジ常時表示に変更し、右クリックメニューにも追加。
  - `ClipView` の右クリックメニューにコピー・切り取り・削除して詰めるを追加（複数選択を維持）。
- `Nanovid/UI/TextClipsPane.swift`
  - 行ビューを `TextClipRow` に切り出し、削除ボタンをホバー時のみ表示＋右クリックメニューを追加。空プロジェクト時のテンプレート絞り込みを非表示化。
- `Nanovid/UI/PreviewView.swift`
  - 空プロジェクト時の案内文言の視認性を改善。
- `Nanovid/UI/ExportView.swift`
  - 解像度・FPS・長さをタイトル下の 1 行サマリーに集約し、設定グリッドとシート高さをコンパクト化。
- `Nanovid/Localizable.xcstrings`
  - 追加したすべての日本語文言に対応する英語訳を追加（`Scripts/check-localization.py` 通過）。

## 4. 残した課題

1. **実機描画・スクリーンショットでの細部調整**:
   - ライトモード／ダークモードおよび英語ロケールで、インスペクタ幅 `276pt`・トラック見出し幅 `148pt`・再生バーの重なり（極端に狭いウィンドウ幅で録音中レベルメータが出た場合など）に窮屈さがないか確認が必要。
2. **ホバー操作の発見性**:
   - 再生バーのコマ送りボタンやトラック見出しのミュート／非表示／ロックは画面の静けさを優先してホバー表示とした。初回利用者への気付きやすさをさらに高める場合、トラック見出しに薄いホバー背景を付けるなどの微調整の余地がある。
3. **音声クリップ選択時の画面確認**:
   - 既存のスクリーンショット状態（`select-text` / `select-media`）には音声クリップ単独選択の状態が無い。`bgm` 選択時に音量＋フェードだけの最小構成になることはコード上確認済みだが、視覚確認もしておくと安心。
4. **未使用キーの整理**:
   - UI から外した一部文言（`テンプレートを変更` など）は `Localizable.xcstrings` に残している。将来的に確定したらカタログからも掃除してよい。

## 5. 2 回目の手直し（PR #26 へのフィードバック）

### 5.1 インスペクタは手動開閉に戻す
選択に合わせた自動開閉は、選ぶたびにプレビューの幅が変わって落ち着かないのでやめた。
素材パネルと同じく既定で閉じ、⌘2 とツールバーのボタンで開閉する。中身の整理（クリップの種類に合う節だけを出す）は残した。

### 5.2 ダークモード
- 色はすべてシステムの色（`.primary` の濃さ・`controlBackgroundColor` など）にし、ライトとダークで同じ明暗の並びになるようにした
- タイムラインのクリップの白文字・黒枠など決め打ちの色を外した
- 確認用に、デバッグビルドだけで効く `--shot-appearance light|dark` を足した（システムの設定は変えず、このアプリだけ）

### 5.3 トランスポートを 1 段に
プレビュー直下の再生の行（34pt＋区切り線 1pt）をなくし、再生・コマ送り・時刻・録音を下段の見出し行（タイムラインでも字幕でも同じ `TransportControls`）に移した。
先頭へ・末尾へのボタンは置かず、「編集操作 > 先頭へ移動 / 末尾へ移動」から。

| 寸法 | 前 | 後 | 差 |
|---|---|---|---|
| プレビュー下の再生の行 | 35pt | なし | −35pt |
| 下段の見出し行 | 32pt | 30pt | −2pt |
| ルーラー | 24pt | 18pt | −6pt |
| トラックの高さ | 56pt | 40pt | −16pt × 本数 |
| トラックの間 | 4pt | 2pt | −2pt × (本数−1) |
| 下段の既定の高さ | 240pt（3 本が収まりきらない） | 186pt（3 本がちょうど収まる。寸法から計算） | −54pt |

1280×800 の窓で測ったプレビュー欄の高さ: **464pt → 561pt（+97pt、約 +21%）**。映像そのものは 448pt → 545pt。

見出し行を 30pt にしたあと、通常サイズのセグメント（24pt）では上下に 3pt しか残らず、横の仕切りの帯（7pt）の下半分が上の余白に足されて上下が偏って見えた。仕切りは並びの中で線の 1pt だけを占め、つかむ範囲は上下へ重ねる形にし、見出し行のコントロールは小さいサイズ（セグメント 20pt、上下 5pt ずつ）にそろえた。

### 5.4 タイムラインは白黒（グレー）
- クリップの紫・青・緑の色分けをやめ、`.primary` の濃さで描く（テロップ 26%・映像と画像 17%・音声 10%）。種類はアイコン（あぁ・フィルム・写真・波形）と濃さで見分ける
- 色を使うのは要所だけ: 選んだクリップの枠（アクセント色）、再生ヘッド（赤）、書き出す範囲の旗（アクセント色）、切り抜き中の範囲（オレンジ）、有効になっているトラックのミュート等（オレンジ）
