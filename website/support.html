よくある質問

録音したファイルはどこにありますか？
プロジェクトの隣の「Recordings」フォルダか、「ムービー」フォルダの「Nanovid Recordings」に WAV ファイルで保存しています。
「素材を開けません」と出ます。
素材を動かしたか、別の Mac から持ってきたプロジェクトです。「ファイル ＞ 素材の場所を指定…」で素材の入ったフォルダを選び、保存し直すと、次からはそのまま開けます。
字幕の自動生成でダウンロードの確認が出ます。
書き起こしに使う言語モデルを、macOS が Apple から取り寄せます。言語ごとに初回だけで、数百 MB になることがあります。書き起こしは Mac の中で行い、音声は外部へ送りません。
窓を閉じるとアプリが終了します。
nanovid は 1 つの窓で 1 つのプロジェクトを編集するアプリなので、窓を閉じると終了します。保存していない変更があれば、終了する前に確認します。

FAQ

Where are my recordings?
They are saved as WAV files in a “Recordings” folder next to the project, or in “Nanovid Recordings” in your Movies folder.
The app says it can’t open some media.
The media was moved, or the project came from another Mac. Choose File › Locate Media… and select the folder that contains the media, then save the project. It will open as is next time.
Automatic subtitles ask to download something.
macOS downloads the language model used for transcription from Apple. This happens only the first time for each language and may be several hundred megabytes. Transcription runs on your Mac, and your audio is not sent anywhere.
Closing the window quits the app.
nanovid edits one project in one window, so closing the window quits the app. If there are unsaved changes, it asks before quitting.
